Comment écrire une fonction
x^2 ou x²puissance

2,5 ou 2.5décimaux
|x-1|valeur absolue
√x, sqrt(x)racine carrée
∛x, rac(3 ; x), ³√xracine n-ième, définie sur [0 ; +∞[ comme au programme ; rac(n ; x) avec n entier ≥ 1 (n peut être un curseur)
x^(1/n)puissance rationnelle, définie pour x > 0 (x ≥ 0)
ln, log, exp, e^xlog népérien, décimal, exponentielle
sin cos tan, arctan arcsin arccosen radians ; π ou pi. arctan : ℝ → ]−π/2 ; π/2[, arcsin : [−1 ; 1] → [−π/2 ; π/2], arccos : [−1 ; 1] → [0 ; π]
E(x) ou ent(x)partie entière : E(x) ≤ x < E(x) + 1. Aux sauts, ● = valeur atteinte, ○ = valeur non atteinte
min(2 ; x)séparateur d'arguments : « ; »
pgcd(12 ; 18), ppcm(x ; 6)PGCD et PPCM d'entiers (définis seulement pour des entiers : la courbe est alors tracée par points)

f(x+1), f'(x)réutiliser une autre fonction ou sa dérivée

Dérivée, intégrale, zéros, extremums et limites sont calculés numériquement : très précis pour les fonctions du programme, mais à confirmer par le calcul. La « valeur exacte probable » (étiquette verte) est une reconnaissance automatique, pas une preuve.
